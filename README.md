# NEMESIS Custom Objectives

AI 이미지를 활용하여 제작한 **NEMESIS 커스텀 목표 카드**입니다.

## 🎯 임무 리스트

|   번호   | 임무                         | 목표                                                                                                                                                                                   |
| :----: | :------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  **1** | **웨이랜드 직속 해결사**            | CEO는 영생의 목표를 위해 당신에게 미션을 내렸습니다.<br><br>에일리언 시체, 에일리언 알, 유충 중 하나를 가진 사람을 **지구로 데려와야 합니다.**                                                                                            |
|  **2** | **함께하는 동안 싹튼 감정**          | **내 다음 후플레이어와 함께 지구로 돌아가야 합니다.**<br><br>내 다음 후플레이어가 사망했다면, **후플레이어의 시체를 가지고 지구로 돌아가야 합니다.**                                                                                          |
|  **3** | **웨이랜드 보안 책임자**            | 인트루더에 대한 정보가 많이 유출되어서는 안 됩니다.<br><br>당신을 제외한 **모든 인원이 지구로 돌아가지 못하거나 사망해야 합니다.**<br><br>그리고 **당신은 지구로 돌아가야 합니다.**                                                                     |
|  **4** | **프로메테우스 엘리자베스 쇼 박사**      | 인간을 만든 존재가 누구인지, 인트루더는 무엇이며 어디에서 왔는지 알기 위해 떠납니다.<br><br>**인트루더 약점 2개 이상이 파악된 상태로 심우주로 가야 합니다.**                                                                                      |
|  **5** | **인트루더 공포 숭배자**            | **여왕이 죽지 않아야 하며, 우주선이 파괴되어서는 안 됩니다.**<br><br>그리고 **당신은 지구로 돌아가야 합니다.**                                                                                                               |
|  **6** | **노멀 플레이어**                | **생존해서 지구로 돌아가야 합니다.**                                                                                                                                                               |
|  **7** | **직접 확인해야하는 수수께끼 인물**      | 당신은 가장 마지막으로 **좌표를 확인 또는 수정**하거나, 남이 만진 **엔진을 수리하는 액션**을 해야 합니다. (고장 가능)<br><br>그리고 **지구 또는 화성으로 가야 합니다.**                                                                           |
|  **8** | **우주 상인**                  | 자의에 의해서든 타인에 의해서든 **당신과의 거래가 2번 이루어져야 합니다.**<br><br>아이템 또는 물체의 **실제 거래가 이루어져야 합니다.**<br><br>그리고 **지구로 돌아가야 합니다.**                                                                    |
|  **9** | **파멸의 씨앗**                 | **인트루더 알을 가진 채 지구 또는 화성에 도착해야 합니다.**                                                                                                                                                 |
| **10** | **동면 속 기적적 생존자**           | 반드시 **동면을 통해 지구에 도착해야 합니다.**<br><br>동면 상태로 지구에 도착하면 **스캐너 과정을 생략하고 승리합니다.**                                                                                                          |
| **11** | **동료애가 깊은 사람**             | 다른 플레이어 1명 이상이 **구명정으로 탈출한 후 구명정으로 탈출**하거나,<br><br>다른 플레이어 1명 이상이 **동면한 후 동면하여 지구로 가야 합니다.**                                                                                         |
| **12** | **기억상실증 - 스스로를 믿지 못하는 사람** | 다음 중 하나를 만족해야 합니다.<br><br>• 퀘스트 카드 **2개를 클리어**<br>• 퀘스트 카드 **2개를 클리어하지 않고 지구로 귀환**                                                                                                   |
| **13** | **유능한 기술자**                | **고장난 방을 2개 이상 수리한 후 지구로 돌아가야 합니다.**                                                                                                                                                 |
| **14** | **인트루더 킬러**                | **성체 이상 인트루더 1마리 사살에 관여**해야 합니다. (피해 1 이상 입힘)<br><br>그리고 **지구로 귀환해야 합니다.**                                                                                                           |
| **15** | **지구에 묻어주고 싶은 전우**         | **당신이 죽으면 이 미션을 공개합니다.**<br><br>당신의 시체를 다른 플레이어가 가지고 **지구로 귀환하면 승리합니다.**<br><br>시체를 든 플레이어는 **팔 부상이 응급처치됩니다.**<br>단, 팔 부상이 2개라면 응급처치되지 않으며 당신을 들 수 없습니다.<br><br>죽지 않았다면 **지구로 귀환해야** |
